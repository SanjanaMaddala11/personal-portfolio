# Personal Portfolio Website

A responsive and interactive portfolio website built using HTML5, CSS3, and vanilla JavaScript for a web development internship final project.

## Features
- Responsive layout using CSS Grid, Flexbox, and media queries
- Mobile navigation menu
- Light/dark theme toggle
- Project search and category filters
- Contact form validation
- Dynamic copyright year
- Semantic HTML and accessible form labels

## Project structure
```text
personal-portfolio-internship/
├── index.html
├── css/style.css
├── js/script.js
├── assets/images/
├── screenshots/
├── README.md
└── report.md
```

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a browser, or use the Live Server extension in Visual Studio Code.
3. Test the navigation, theme button, project search/filter, and form validation.

## Publish with GitHub Pages
1. Push the project to a public GitHub repository.
2. Open **Settings → Pages**.
3. Under the build/deployment section, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. Wait for the deployment to finish and open the published URL shown on the Pages settings screen.

## Customization before submission
- Confirm your name and update the contact information in `index.html`.
- Replace sample project cards with projects you have actually completed.
- Add real screenshots to the `screenshots/` folder.
- Update `report.md` with your own testing, challenges, and learning experience.

## Technologies
HTML5, CSS3, JavaScript (ES6), Git, GitHub, GitHub Pages.
